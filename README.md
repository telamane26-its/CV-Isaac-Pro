# Isaac — CV en ligne professionnel 🚀

Site web moderne et interactif présentant le parcours académique, les compétences et les projets d'**Isaac**, étudiant en classe préparatoire aux grandes écoles d'ingénieurs à l'**ESEO Angers**.

---

## 🌟 Aperçu du site

Le site est conçu avec un design soigné, fluide et responsive, mettant en valeur :
- **À propos** : Présentation du profil et des objectifs d'ingénierie.
- **Formation** : Parcours académique à l'ESEO Cours Lumière.
- **Compétences** : Compétences scientifiques (Maths, Physique, SI) et informatiques (Web, Algorithmique).
- **Projets** : Réalisations et initiatives académiques et personnelles.
- **Contact** : Formulaire interactif et coordonnées directes.

---

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique et accessible.
- **CSS3** : Design moderne, animations fluides, typographies Google Fonts (*Inter* & *Playfair Display*).
- **JavaScript (ES6+)** : Gestion des interactions, navigation dynamique et validations.

---

## 🚀 Lancement local

Pour consulter le site en local :
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/telamane26-its/CV-Isaac-Pro.git
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur préféré.
